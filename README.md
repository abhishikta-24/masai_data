# BigBasket Capstone Analytics Dashboard

This repository serves as a fully reproducible end-to-end data engineering and analytics portfolio analyzing BigBasket transaction records through a structured repo file and folder layout.
To completely regenerate the database and raw exports from scratch, clear the local workspace of old tracking logs and run the data generator script via `python3 generate_data.py`, which populates the messy data spreadsheet workbooks named `orders_raw.csv` and `products.csv` alongside the core relational SQLite warehouse file `bigbasket_capstone.db`. Individual SQL task queries are organized systematically into autonomous scripts within the root folder, where initial row audits live inside `verify.sql`, fundamental syntax operations live inside `01_foundations.sql`, and multi-table calculations live inside `02_aggregation_joins.sql`, directly feeding the core file `03_reporting.sql` to export the final tabular spreadsheet `monthly_category_revenue.csv`. All processed metrics hook directly into a public business intelligence layer accessible via the [Live Tableau Public Dashboard Link](https://public.tableau.com/authoring/performanceDashboard/Dashboard1#1), which cross-references the performance breakdowns in the [Data Story Brief](DATA_STORY.md), the structural prompt framework in the [AI Interaction Log](ai_log.md), and the data cleaning loops inside the [Part 4 Python/Pandas Notebook File](part4_notebook.ipynb).
